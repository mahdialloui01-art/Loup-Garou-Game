# Castle Destroyer (Android)

A separate Godot 4.4.1 mobile castle-siege game inside this repository. The original Loup Garou project at the repository root is intentionally untouched.

## Current prototype
- Landscape Android layout.
- Two destructible castles built from individual wall blocks.
- Normal and heavy player cannon shots.
- AI opponent that fires back.
- Hit detection, block damage, debris particles, score, health indicators, victory/defeat and restart/pause controls.
- Procedural graphics; no third-party game assets required.

## Open in Godot
Open the `CastleDestroyer/project.godot` file with Godot 4.4.1 or later.

## Android build
The dedicated workflow `CastleDestroyer-Android` exports a debug APK artifact for installation and testing. It is not a release-signed Play Store package.
